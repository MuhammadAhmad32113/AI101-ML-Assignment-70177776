1. Introduction

Compressive strength is the quintessential metric governing structural concrete safety, traditionally evaluated through destructive laboratory compression testing requiring up to 28 days of wet curing. Formulating reliable machine learning models enables civil engineers to rapidly optimize mix designs, reduce waste, and predict early-age strength. In this investigation, five predictive models were trained and tuned: Linear Regression (baseline), Polynomial+Ridge Regression, Random Forest, Gradient Boosting, and a Multi-Layer Perceptron (MLPRegressor). Main finding: Tuned Gradient Boosting with engineered domain features (water-to-cement ratio and log-curing age) achieved a test RMSE of 4.270 MPa (R^2 = 0.9292), yielding a 35.0% error reduction over standard linear regression.

2. Problem Statement

Given an input vector x in R^8 detailing mix proportions (cement, blast furnace slag, fly ash, water, superplasticizer, coarse aggregate, fine aggregate in kg/m^3) and sample curing age (days), the goal is to learn a mapping f: R^8 to R predicting compressive strength y in MPa. The relationship is fundamentally non-linear, as concrete exhibits rapid logarithmic strength growth within early days followed by asymptotic flattening. Performance is measured via Root Mean Squared Error (RMSE), Mean Absolute Error (MAE), and Coefficient of Determination (R^2).

3. Dataset Used

We utilize the Concrete Compressive Strength dataset from the UCI Machine Learning Repository (id=165) curated by Yeh [1]. The dataset comprises 1,030 experimental formulations tested across standard cylindrical specimens. No missing values exist. Crucially, domain feature engineering was performed by incorporating: (1) water-to-cement ratio (Water / Cement), and (2) logarithmic curing age log(Age). All preprocessing transformations were embedded inside scikit-learn Pipeline objects fitted exclusively on the training split, completely eliminating data leakage.

5. Methodology

5.1 Learning Setting

Supervised regression was conducted comparing: (1) Ordinary Least Squares Linear Regression as a linear baseline; (2) Polynomial feature expansion (degree 2 and 3) coupled with L2 Ridge regularisation; (3) Random Forest Regressor; (4) Gradient Boosting Regressor; and (5) a feedforward Multi-Layer Perceptron (MLPRegressor). All predictors were scaled using StandardScaler inside pipelines.

5.2 Data Split Approach

An 80/20 train/test split was established with random seed 42. Five-fold cross-validation was conducted exclusively across the 824 training samples for hyperparameter tuning using negative mean squared error scoring. Final evaluation was performed strictly once on the held-out 206 test samples.

6.2 Analysis

Why Linear Baseline Under-Performs: Linear regression assumes constant marginal returns for all inputs. However, cement hydration kinetics are strictly non-linear: strength increases logarithmically with age and inversely with water content (Abrams' law). Fitting a linear plane to curved hydration trajectories violates linearity and homoscedasticity assumptions, resulting in severe residual variance.

Impact of Engineered Features: Incorporating water/cement ratio and log(age) dramatically improved every model. Linear Regression RMSE plummeted from 9.796 to 6.573 MPa (R^2 jumped from 0.6276 to 0.8323, a massive +32.6% error reduction). Tree-based models also gained noticeably (GB RMSE dropped from 4.658 to 4.420 MPa), confirming that explicitly providing physically grounded ratios simplifies decision partitioning.

Error Analysis & Feature Importance: Feature importance analysis showed that Age (35.2%), Water/Cement ratio (28.4%), and Cement (18.1%) dominate strength predictions. Stratified residual analysis across age bins revealed that young specimens (1–7 days) exhibited higher relative percentage error due to high chemical sensitivity during initial setting reactions, whereas mature specimens (>90 days) exhibited the lowest absolute variance.

7. Conclusion

Gradient Tree Boosting integrated with domain-specific features (water/cement ratio and logarithmic age) accurately predicts concrete compressive strength (RMSE 4.270 MPa, R^2 = 0.9292). Incorporating domain-guided non-linear transformations significantly enhances both parametric and non-parametric algorithms. Future work could integrate aggregate grading curves and curing temperature records.
