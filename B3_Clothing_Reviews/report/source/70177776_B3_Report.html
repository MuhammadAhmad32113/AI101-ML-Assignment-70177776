1. Introduction

Consumer sentiment and star ratings are fundamental to retail recommendation systems, customer satisfaction monitoring, and automated catalog curation. In this work, we analyze the Women's E-Commerce Clothing Reviews benchmark comprising 23,486 customer transactions. We address multi-class ordinal classification (1–5 stars) characterized by heavy positive skew ($\sim$55% 5-star ratings). Adhering strictly to anti-leakage guidelines, we exclude the concurrent feedback indicator Recommended IND. Our primary empirical finding shows that balanced multinomial Logistic Regression achieves a peak macro-F1 of 0.4850 on the 5-class problem (ordinal MAE 0.4639 stars on test), and reframing the problem into a 3-class business orientation (Negative, Neutral, Positive) drastically increases macro-F1 to 0.6517 with 81.34% accuracy.

2. Problem Statement

Formally, given a review record $\mathbf{x} = (\mathbf{x}_{ ext{struct}}, \mathbf{x}_{ ext{text}})$, we predict the ordinal target $y \in \{1, 2, 3, 4, 5\}$. We evaluate models via Macro-averaged F1, Weighted-F1, Accuracy, and Ordinal MAE ($ rac{1}{N} \sum |\hat{y}_i - y_i|$). Data Leakage Ban: The column Recommended IND was explicitly dropped prior to any feature extraction. Because shoppers fill recommendation checkboxes concurrently with star selections, this feature represents a direct proxy of the label that would be unavailable at runtime when inferring customer sentiment from review text alone.

3. Dataset Used & Preprocessing

We utilize the Women's E-Commerce Clothing Reviews dataset (Kaggle: nicapotato/womens-ecommerce-clothing-reviews). Filtering empty narrative entries removes 845 observations, leaving 22,641 clean reviews. Review title and body text are merged into a single narrative channel. Text representations are vectorized via TF-IDF (10,000 unigram/bigram features with sublinear term-frequency scaling). Structured covariates include customer Age, $\log(1 + ext{Positive Feedback Count})$, character review length, and one-hot encodings for Division, Department, and Class.

5. Methodology

5.1 Preprocessing & Modality Pipelines

To avoid test leakage, all preprocessing pipelines are encapsulated within ColumnTransformer. Numerical features are scaled via StandardScaler; categorical variables are one-hot encoded with rare level handling; text is vectorized using TF-IDF. Three modalities are constructed: Structured Only, Text Only, and Combined.

5.2 Learning Setting & Class Weighting

We benchmark three learning paradigms under unweighted and cost-sensitive balanced class weighting: (i) Multinomial Logistic Regression (L-BFGS), (ii) Linear Support Vector Classifier (LinearSVC), and (iii) Random Forest (75 trees, max depth 25).

6.2 Label Ambiguity & 3-Class Reframing

Inspection of 5-class test errors highlights severe confusion between adjacent ratings: Ratings 4 vs. 5 accounts for 560 misclassifications (211 4$ o$5; 349 5$ o$4). This stems from inherent label subjectivity: two reviewers using identical enthusiastic praise ("fits great, vibrant color") often assign 4 or 5 stars based purely on individual leniency. Reframing the task into 3 classes (Negative 1–2, Neutral 3, Positive 4–5) eliminates this artificial boundary, boosting Test Macro-F1 from 0.4800 to 0.6517 and Test Accuracy to 81.34% (Table V).

6.3 Qualitative Misclassification Analysis

Qualitative inspection of test reviews highlights distinct error mechanisms: (i) Sarcasm/Mixed Critiques: "Too sheer... absolutely see-thru. great style and beautiful fabric" (True: 2 stars $ o$ Pred: Positive), where bag-of-words picks up "great style" and "beautiful"; (ii) Hedging: "super cute, but did walk away... ran back next day" (True: 5 stars $ o$ Pred: Negative); (iii) Subtle Irony: "all that's missing is a bonnet!" (True: 3 stars $ o$ Pred: Positive).

7. Conclusion

Review text overwhelmingly drives e-commerce rating predictions. Balanced class weighting is essential to prevent majority collusion under 55% positive skew. Reframing to 3-class sentiment provides a substantially more robust operational model (81.3% accuracy, 0.6517 Macro-F1). Future work should examine pretrained BERT transformers with ordinal loss functions.
