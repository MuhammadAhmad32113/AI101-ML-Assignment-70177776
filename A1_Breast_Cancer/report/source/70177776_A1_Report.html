1. Introduction

Breast cancer is the most prevalent malignant neoplasm affecting women worldwide, making prompt and precise computer-assisted histological diagnosis crucial for clinical survival rates. Diagnostic needle biopsies generate microscopic cell-nucleus morphometry where automated machine learning triage can substantially diminish clinician diagnostic fatigue. In this investigation, four predictive models—penalized Logistic Regression (baseline), Support Vector Machines (SVM-RBF), Random Forest, and Gradient Boosting—were constructed and systematically tuned using stratified nested cross-validation. Main finding: Linear and RBF kernel classifiers both attained an outstanding test F1-score of 0.9762 and ROC-AUC > 0.996, proving that regularized linear decision boundaries fully capture nuclear morphometric separability while preventing medical false negatives.

2. Problem Statement

Given an input feature vector x in R^30 capturing ten morphological cell properties across three statistical descriptors (mean, standard error, and worst/largest), the objective is to learn a mapping f: R^30 to {0, 1}, predicting whether a biopsy mass is malignant (y=0) or benign (y=1). Crucially, in medical screening contexts, a false negative (predicting benign when malignancy exists) carries fatal consequences, whereas a false positive incurs merely confirmatory pathology. Hence, model selection is constrained by maximizing malignant Recall and malignant F1-score at minimal precision degradation.

3. Dataset Used

We utilize the Breast Cancer Wisconsin (Diagnostic) Dataset from the UCI Machine Learning Repository [1]. Features were computed from digitised images of fine needle aspirates (FNA) of breast masses, describing characteristics of cell nuclei present in the image. The 30 real-valued features encompass radius, texture, perimeter, area, smoothness, compactness, concavity, concave points, symmetry, and fractal dimension. No missing values or corrupt data exist. All feature standardizations were integrated strictly within scikit-learn Pipeline wrappers fitted solely on training splits, rigorously preventing data leakage.

5. Methodology

5.1 Learning Setting

Supervised binary classification was conducted comparing: (1) Logistic Regression with L1/L2 regularization as an interpretable linear baseline; (2) SVM with Radial Basis Function (RBF) kernel for non-linear boundary projection; (3) Random Forest ensemble; and (4) Gradient Tree Boosting. All inputs were scaled via StandardScaler within pipeline steps.

5.2 Data Split Approach

A stratified 80/20 train/test split was established with random seed 42. Five-fold stratified cross-validation was performed exclusively on the 455 training samples for hyperparameter tuning. Test evaluation occurred exactly once on the held-out 114 samples.

6.2 Analysis

Why Accuracy Alone is Misleading: In clinical diagnosis, false negatives are catastrophic. A trivial classifier predicting the majority class (benign) achieves 62.7% accuracy while missing every tumour. Here, Logistic Regression and SVM yielded only 1 false negative each, whereas Gradient Boosting missed 4 malignant patients despite having high 95.6% accuracy.

Threshold Sweep Analysis: Shifting the malignant classification decision threshold to 0.59 guaranteed a malignant recall of ≥ 0.95 (0.9524), reducing malignant false negatives to a strict minimum while precision remained virtually unchanged (0.9756 vs. 0.9762), incurring a negligible precision cost of 0.0006.

Feature Importance & Redundancy Ablation: Analysis revealed that worst concave points, worst radius, and mean concavity dominated decision weights. Pruning 8 highly collinear geometric features (|r| > 0.90, e.g., dropping perimeter/area in favor of radius) caused virtually zero change in F1 score (0.9762 vs. 0.9762 for LR and SVM; AUC decreased by only 0.001), corroborating that regularized linear and kernel models inherently discard redundant geometric scaling.

7. Conclusion

Regularized Logistic Regression and RBF-SVM deliver state-of-the-art diagnostic discrimination for fine-needle aspirate morphometry, achieving 0.9762 F1 and >0.996 AUC on unseen test biopsies. Shifting the operating threshold provides rigorous clinical safety against false negatives with negligible precision loss. Future work could incorporate deep learning models directly on raw FNA cytological micrographs.
